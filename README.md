# Personal Automation System (ATLAS)

## Your Complete Personal Assistant for Smart Living

Transform your daily life with an integrated automation platform combining financial management, smart home control, and workflow automation.

---

## 🌟 Features

### 💰 Financial Management
- Expense tracking with categories
- Income management
- Budget planning and monitoring
- Savings goals
- Loan and credit card tracking
- Financial analytics and insights

### 🏠 Smart Home Control
- Control Alexa-enabled devices
- Roku smart bulbs integration
- Amazon Basics bulbs support
- SmartRent system integration
- Door lock control
- Thermostat management
- Quick scenes and routines

### ⚡ Automation & Workflows
- Create custom automation workflows
- N8N integration for advanced workflows
- Scheduled tasks
- Event-based triggers
- One-click routines

### 🔒 Security & Privacy
- Firebase Authentication
- Session management with auto-logout
- Activity logging and audit trail
- Firestore security rules
- Environment-based configuration
- MFA support (coming soon)

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Configure environment
cp .env.example .env

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to Firebase
firebase deploy
```

For detailed setup instructions, see [SETUP_GUIDE.md](./SETUP_GUIDE.md)
